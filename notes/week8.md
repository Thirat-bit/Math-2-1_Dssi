## สูตรที่ใช้

- **โมเดล SLR** — ŷ = β̂₀ + β̂₁x  ·  RSS = Σ(y−ŷ)²
- **SE(β̂₁)** — = √[ MSE / Σ(xᵢ − x̄)² ]  โดย MSE = RSS/(n−2)
- **RSE** — = √MSE
- **t และ p-value** — t = β̂₁ / SE(β̂₁), df = n − 2, p = `2 * stats.t.sf(|t|, df)`
- **โมเดล log-linear** — y = log(x) → แปลงกลับด้วย `exp(ŷ)`

## จุดที่คนตกบ่อย

- **Intercept คือค่าทำนายเมื่อ x = 0** — ซึ่งมักอยู่นอกช่วงข้อมูล → ตีความอย่างระวัง
- **residual = y − ŷ** — ไม่ใช่ ŷ − y
- **p-value ใช้ค่า t ของความชัน** — ไม่ใช่ของ intercept
- **Test MSE ต้อง fit บน train 960 แถว** — แล้ววัดบน test 243 แถว
