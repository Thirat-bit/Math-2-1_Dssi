## สูตรที่ใช้

- **Test MSE** — = Bias² + Variance + Var(ε)
- **Bias²** — = (ค่าเฉลี่ยค่าทำนาย n ครั้ง − f(x₀))²
- **Variance** — = ความแปรปรวนของค่าทำนาย n ครั้ง (`np.var` = หาร n)
- **Var(ε)** — = σ² ของ noise ที่โจทย์ให้มา
- **Test error rate** — (จำแนกกลุ่ม) = 1 − accuracy

## จุดที่คนตกบ่อย

- **`PolynomialFeatures(d)` ให้คอลัมน์ d+1 ตัว** — `[1, x, …, xᵈ]` → สัมประสิทธิ์ของ xᵈ อยู่ที่ **`coef_[d]`** ไม่ใช่ `coef_[d-1]`
- **`np.polyfit` คืนสัมประสิทธิ์กลับด้าน** — จากกำลังสูงสุดมาต่ำสุด → `[0]` คือ xᵈ
- **f(x) = 5 + 2·sin(2πx) มุมเรเดียน** — ต้องเขียน `5 + 2*np.sin(2*np.pi*x)`
- **แบ่งตามคอลัมน์ `set`** — ไม่ใช่ตำแหน่งแถว (ยกเว้นข้อ 6.10 ที่ใช้ไฟล์อื่น)
