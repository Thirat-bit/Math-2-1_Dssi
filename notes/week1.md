> สรุปประกอบการอ่าน — รายละเอียดของแต่ละข้ออยู่ในโน้ตบุ๊ก

## สูตรที่ใช้

- **L2 norm** (ความยาวเวกเตอร์) — ‖x‖ = √(x₁² + x₂² + … + xₙ²) → `np.linalg.norm(x)`
- **cosine similarity** — cos(s,p) = (s·p) / (‖s‖‖p‖) → `s @ p / (norm(s)*norm(p))`
- **มุมระหว่างเวกเตอร์** — θ = arccos(cos) แล้วแปลงเป็นองศา → `np.degrees(np.arccos(c))`
- **dot product** — s·p = Σ sᵢpᵢ → `s @ p`
- **ระยะ Euclid** — d = √(Σ (sᵢ−pᵢ)²) → `np.linalg.norm(s - p)`

## จุดที่คนตกบ่อย

- **ห้าม standardize** — สัปดาห์นี้ใช้ค่าตามหน่วยในไฟล์ตรง ๆ ทุกข้อ
- **“ลูกค้าแถวที่ r” นับจาก 0** — เรียงตามลำดับในไฟล์ → ใช้ `df.iloc[r]` ไม่ใช่ `.loc`
- **เรียงคอลัมน์ตามที่โจทย์เขียนทุกครั้ง** — แต่ละข้อใช้ชุดตัวแปรต่างกัน
- **ตัดตัวเองออก** — ในข้อที่นับจำนวนคน / หาค่าต่ำสุด (ข้อ 1.4, 1.5, 1.8)
- **อย่าปัดเศษก่อนเทียบ threshold** — ข้อ 1.4 ต้องเทียบด้วยค่าเต็ม
