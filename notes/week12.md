## สูตรที่ใช้

- **LDA** — ทุกคลาสใช้ covariance **เดียวกัน** → ขอบเขตเป็นเส้นตรง
- **QDA** — covariance **ต่างกันได้** → ขอบเขตเป็นเส้นโค้ง
- **Gaussian Naive Bayes** — ตัวแปร **อิสระกันในคลาส**
- **KNN** — ไม่มีสมมติฐาน ใช้ระยะทาง → ต้อง standardize
- **`predict(X)`** — = คลาสที่ความน่าจะเป็นสูงสุด (ใช้ threshold ของตัวเองไม่ได้)
- **`predict_proba(X)`** — คอลัมน์ 0 = คลาส 0, คอลัมน์ 1 = คลาส 1 → ดึง **`[:, 1]`**

## จุดที่คนตกบ่อย

- **`predict_proba(X)[:, 1]` ต้องดึงคอลัมน์ที่ 1** — ไม่งั้นจะได้ความน่าจะเป็นของคลาส 0
- **fit scaler บน train แล้วใช้ตัวเดียวกับ test** — ใช้ `make_pipeline(StandardScaler(), KNeighborsClassifier(...))`
- **ถ้า QDA ไม่ดีกว่า LDA** — มักแปลว่าข้อมูลเกือบเป็น Gaussian รูปทรงเดียวกัน → LDA พารามิเตอร์น้อยกว่าจะดีกว่า
- **K ต้องเป็นเลขคี่** — สำหรับ classifier
