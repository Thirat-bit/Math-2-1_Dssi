## สูตรที่ใช้

- **โมเดล MLR** — y = β₀ + β₁x₁ + … + βₚxₚ → `smf.ols('y ~ x1 + x2', data=df).fit()`
- **t-statistic** — = β̂ / SE(β̂) → `model.tvalues['x']`
- **Adjusted R²** — ชดเชยจำนวนตัวแปร → `model.rsquared_adj`
- **AIC / BIC** — `model.aic`, `model.bic` — **ยิ่งต่ำยิ่งดี**
- **95% CI** — ของค่าเฉลี่ย → `model.conf_int(alpha=0.05)`
- **Prediction Interval** — กว้างกว่า CI เสมอ (มี Var(ε) เพิ่ม)

## จุดที่คนตกบ่อย

- **CI ≠ PI** — CI = ช่วงของค่าเฉลี่ย E[y|x] · PI = ช่วงของค่าของคนรายหนึ่ง → คนละตัวใน `conf_int()`
- **BIC โทษตัวแปรเพิ่มหนักกว่า AIC** — เพราะมีบทลง ln n
- **multicollinearity** — ทำให้ SE โต → |t| เล็กลง แต่ R² ยังสูง
- **Backward elimination** — ตัดทีละตัวแปรที่ p-value สูงสุดจนได้โมเดลสุดท้าย
